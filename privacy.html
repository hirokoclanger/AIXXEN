2. What this notice covers

This notice covers the public AIXXEN website at aixxen.com. Customers using the AIXXEN application receive a separate Data Processing Agreement (DPA) covering tenant-scoped processing.

3. Information we collect on this website

The marketing site is intentionally minimal:

  • Cookie consent choice. Stored in your browser (localStorage) so we know which cookie categories you allow.
  • Server logs. Standard hosting logs (IP address, user-agent, request path, timestamp) retained for security and operational purposes for up to 30 days.
  • Email contact. If you write to sales@aixxen.com, we keep that correspondence in a standard email account.

We do not currently run any analytics, marketing, or tracking scripts on this site. If we add any, the cookie banner will reflect them and require your consent before they load.

When you become a customer, the application processes data your organisation provides via CSV / Excel / API: tools, spend, headcount, use cases, and anonymous capability survey responses. Survey responses are aggregated with k≥5 anonymity suppression. Specifics are governed by the customer DPA.
